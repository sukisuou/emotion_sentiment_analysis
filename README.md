# NLP PROJECT : Emotion Sentiment Analysis
## Title: 
Multilabel Emotion Detection using TF-IDF & MLP Neural Network
Dataset used: GoEmotion by Google
### Group Members: Adam Idlan, Adam Hakimi, Adam Iskandar

## Directory:
1) `emotion_hf.py` : data processing, visualization and pipelining for training
2) `emotion_train.py` : MLP model training with Tensorflow, Keras and ScikitLearn, with TF-IDF text vectorization
3) `emotion_validate.py` : validation code using unseen data
4) `app/main.py` : main code for deployment
5) `app/emotion_dataset.pkl` : dataset for training
6) `data_dist.txt` and `training_log.txt` : data insight and training history
7) `zzzz_scrap_emotion.py` : failed attempt with scikit (kept in for proof of learning)
